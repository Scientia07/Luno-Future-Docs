Frameworks

Remotion

Create videos programmatically with React. Perfect for code walkthroughs, data viz, and technical explainers.

React TypeScript Node.js FFmpeg

Renders at 60fps, exports to MP4/WebM/GIF. Full React ecosystem available.

Open Project Docs

Manim

Mathematical animation engine by 3Blue1Brown. Ideal for equations, proofs, and physics visualizations.

Python LaTeX Cairo FFmpeg

Precise mathematical rendering with beautiful animations. Outputs MP4/GIF/SVG.

Open Project Docs

Three.js

3D graphics library for the web. Perfect for interactive physics simulations and 3D visualizations.

JavaScript WebGL Browser-Native

Runs directly in browser. Interactive, real-time 3D graphics.

Quick Setup

Remotion Setup

# Navigate to remotion folder cd animation-lab/remotion # Install dependencies npm install # Start development server npm start # Render to MP4 npm run build

Manim Setup

# Create virtual environment cd animation-lab/manim python -m venv venv source venv/bin/activate # Linux/Mac # Install manim pip install -r requirements.txt # Render a scene manim -pql scenes/math_equations.py EquationScene

Three.js

# No setup required! Just open in browser: open animation-lab/threejs/physics-demo.html # Or serve locally for best experience: npx serve animation-lab/threejs
