Motion Canvas
Offline

Programmatic animation engine for creating video-quality animated explanations. Pro-level animations through code.

📊 High Skill
⚡ Pro Animations
★ ★ ★ ★ ★
Lang TypeScriptTSX
Type Node.js animation engine - uses @motion-canvas/core + @motion-canvas/2d
Assets TypeScript scene files (.tsx) that define animations programmatically using generator functions. Each scene yields animation steps.
Tools Node.js 18+, VS Code, terminal. Has its own editor UI at localhost:9000. Exports to MP4/GIF.
Workflow Create scenes in TSX → use yield* for animation sequences → preview in editor → render to video file
Your demo is a static HTML recreation with canvas. Real Motion Canvas uses TypeScript generators - great for learning programmatic animation.

Scrollytelling
Offline

Narrative-driven scroll experiences with parallax, sticky sections, and progressive reveals. Highly engaging storytelling.

📊 High Skill
⚡ Excellent
★ ★ ★ ★ ★
Lang HTMLCSSJS
Type Custom code pattern - not a library, but a technique using IntersectionObserver, CSS position: sticky, and scroll events.
Assets HTML sections with content, images, and background media. CSS handles parallax and sticky positioning. JS triggers animations on scroll.
Tools Text editor only. Optional: GSAP ScrollTrigger for advanced effects. No build tools, no npm.
Workflow Structure content in sections → add IntersectionObserver for reveals → CSS transforms for parallax → test scroll behavior
Your demo is a real implementation - this is pure HTML/CSS/JS. Scrollytelling is a pattern, not a framework. You already know the real workflow.

GSAP + Lenis
Offline NEW

Premium scroll animations with horizontal scrolling, pinning, counters, path drawing, and buttery smooth Lenis scroll. Agency-quality effects.

📊 High Skill
⚡ Pro Scroll
★ ★ ★ ★ ★
Lang JavaScriptCSS
Type Two JS libraries combined - GSAP (gsap.com) for animations + Lenis (lenis.darkroom.engineering) for smooth scroll.
Assets HTML sections + JS that registers ScrollTrigger animations. Define what animates, when, and how based on scroll position.
Tools Text editor. GSAP + ScrollTrigger + Lenis via CDN. Free for most uses (GSAP has a paid "Business" license for SaaS).
Workflow gsap.registerPlugin(ScrollTrigger) → gsap.to(el, { scrollTrigger: {...}, ... }) → Lenis wraps native scroll for smoothness
Your demo is a real GSAP + Lenis implementation with horizontal scrolling, pinning, and counters. This is the industry standard for premium scroll effects.

⚡ Interactive

Recommendations by Use Case

School Program Concepts

Best choices: Scrollytelling or Gamma Style - they tell a story and look professional without overwhelming.

Technical Workshops

Best choices: Slidev or Reveal.js - perfect for code examples and technical content.

Marketing to Decision Makers

Best choices: Framer Style or Motion Canvas - premium feel that impresses.

Quick Turnaround

Best choice: Gamma Style - fastest to create while still looking professional.

Offline Distribution

Best choices: Scrollytelling, Reveal.js, or Lottie + HTML - work without internet.

Maximum Engagement

Best choices: Scrollytelling or Framer Style - most interactive and memorable.

Data-Heavy Reports

Best choice: ECharts - interactive charts, drill-downs, and real-time data visualization.

Wow-Factor Presentations

Best choice: Impress.js - 3D spatial transitions that leave lasting impressions.
