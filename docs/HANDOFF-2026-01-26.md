## Key Information for PRDs

### Slidev
- **Category:** Developer slides
- **Dependencies:** Google Fonts (Fira Code, Inter)
- **Key Features:** Terminal styling, code highlighting, touch support
- **Demo:** `/slidev/`

### Motion Canvas
- **Category:** Animation engine
- **Dependencies:** Canvas API only (no external)
- **Key Features:** 30-second animations, scene markers, video export potential
- **Demo:** `/motion-canvas/`

### Gamma
- **Category:** Card-based layout
- **Dependencies:** Google Fonts (Inter)
- **Key Features:** Light theme, card layout, timeline, pricing grid
- **Demo:** `/gamma-guide/`

### Framer
- **Category:** Premium design
- **Dependencies:** Google Fonts (Inter), Intersection Observer
- **Key Features:** Parallax, marquee, scroll animations
- **Demo:** `/framer-guide/`

### Lottie
- **Category:** Vector animation
- **Dependencies:** Lottie Player (unpkg CDN)
- **Key Features:** Lottie JSON animations, speed control, Intersection Observer
- **Demo:** `/lottie-html/`

### Scrollytelling
- **Category:** Scroll narrative
- **Dependencies:** None (vanilla JS)
- **Key Features:** Progress dots, horizontal scroll, sticky sections, parallax
- **Demo:** `/scrollytelling/`

## Context for Next Session

The documentation architecture is designed to:
1. **Scale:** New frameworks just add folders following templates
2. **Discover:** INDEX.md is single source of truth
3. **Research:** Active research flows to completed or archive
4. **Standardize:** All docs have metadata and cross-references

The Reveal.js PRD serves as the **reference implementation** - all other PRDs should follow its structure.
