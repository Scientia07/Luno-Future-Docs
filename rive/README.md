# Rive Interactive Animations Demo

> State-machine driven animations for interactive web experiences

## Quick Start

Open `index.html` in a browser or serve via HTTP:

```bash
python -m http.server 8080
# Open http://localhost:8080/rive/
```

## Features

- **State Machine Demo** - Interactive states (idle, hover, click, success)
- **Animation Types** - UI elements and illustration examples
- **Code Examples** - Integration snippets
- **Accessibility** - Reduced motion support, keyboard navigation

## About Rive

Rive creates interactive animations with state machines. Unlike video or GIF:

| Feature | Rive | Video/GIF |
|---------|------|-----------|
| File Size | ~50KB | 1-5MB |
| Interactive | ✅ Yes | ❌ No |
| State Machines | ✅ Yes | ❌ No |
| Runtime Control | ✅ Yes | ❌ No |

## Note

This demo uses placeholder animations. For production:

1. Create animations in Rive Editor
2. Export as `.riv` file
3. Load with `@rive-app/canvas` runtime
