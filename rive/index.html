Rive Interactive Animations

State-machine driven animations that respond to user input in real-time

Bring Your UI to Life

Rive is a powerful animation tool that creates interactive, state-based animations. Unlike traditional animation formats, Rive animations can respond to user input, making them perfect for buttons, loaders, characters, and more.

Why Rive?

⚡

State Machines

Define complex animation states and transitions. Animations respond to inputs like hover, click, or custom triggers.

🎨

Design + Code

Create in the Rive editor, export as a tiny .riv file, and control via JavaScript. Perfect designer-developer workflow.

📦

Tiny File Size

Rive files are incredibly small compared to video or GIF. A complex animation can be under 50KB.

🔄

Runtime Control

Change colors, text, and animation states at runtime. Perfect for theming and personalization.

📱

Cross-Platform

Use the same .riv file on web, iOS, Android, Flutter, React Native, and more. One animation, everywhere.

🎯

Accessibility

Built-in support for reduced motion preferences. Animations can be paused or simplified automatically.

Integration Code

// Include Rive runtime
<script src="https://unpkg.com/@rive-app/canvas"></script>

// Initialize a Rive animation
const rive = new Rive({
    src: 'animation.riv',
    canvas: document.getElementById('canvas'),
    autoplay: true,
    stateMachines: 'State Machine 1',
    onLoad: () => {
        // Get state machine inputs
        const inputs = rive.stateMachineInputs('State Machine 1');
        const trigger = inputs.find(i => i.name === 'click');

        // Fire trigger on click
        canvas.addEventListener('click', () => trigger?.fire());
    }
});
