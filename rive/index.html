Rive Interactive Animations

State-machine driven animations that respond to user input in real-time

Bring Your UI to Life

Rive is a powerful animation tool that creates interactive, state-based animations. Unlike traditional animation formats, Rive animations can respond to user input, making them perfect for buttons, loaders, characters, and more.

Why Rive?

⚡

State Machines

Define complex animation states and transitions. Animations respond to inputs like hover, click, or custom triggers.

🎨

Design + Code

Create in the Rive editor, export as a tiny .riv file, and control via JavaScript. Perfect designer-developer workflow.

📦

Tiny File Size

Rive files are incredibly small compared to video or GIF. A complex animation can be under 50KB.

🔄

Runtime Control

Change colors, text, and animation states at runtime. Perfect for theming and personalization.

📱

Cross-Platform

Use the same .riv file on web, iOS, Android, Flutter, React Native, and more. One animation, everywhere.

🎯

Accessibility

Built-in support for reduced motion preferences. Animations can be paused or simplified automatically.

Integration Code

// Include Rive runtime
<script src="https://unpkg.com/@rive-app/canvas"></script>

// Initialize a Rive animation
const rive = new Rive({
    src: 'animation.riv',
    canvas: document.getElementById('canvas'),
    autoplay: true,
    stateMachines: 'State Machine 1',
    onLoad: () => {
        // Get state machine inputs
        const inputs = rive.stateMachineInputs('State Machine 1');
        const trigger = inputs.find(i => i.name === 'click');

        // Fire trigger on click
        canvas.addEventListener('click', () => trigger?.fire());
    }
});

Create Your Own Rive Animations

Everything you need to go from idea to interactive animation on your website.

What You Need

🌐 Rive Editor

Free web-based editor at rive.app/editor. No install needed, runs in Chrome/Edge.

Free Tier Browser-based

📦 Rive Runtime

One script tag to load animations on your site. No build tools, no npm required.

Free & Open Source ~150KB

🎨 Design Skills

Basic vector design knowledge helps. Rive's editor has Pen, Shape, and Bone tools similar to Figma.

Beginner-Friendly Tutorials Available

💻 Web Basics

HTML + a few lines of JavaScript to embed and control the animation. No frameworks needed.

No Framework Required

The Workflow: Idea to Interactive Animation

1

Design Your Artboard

Open the Rive Editor and create your visual elements using built-in vector tools (shapes, pen, boolean operations) or import SVGs from Figma/Illustrator.

  • Create shapes with the Pen and Shape tools
  • Import SVG files from Figma, Illustrator, or Inkscape
  • Use Bones for character rigging (arms, legs, facial expressions)
  • Organize layers and groups for clean animation targets
2

Animate on the Timeline

Use keyframes to animate properties like position, rotation, scale, opacity, and color. Rive supports easing curves for smooth motion.

  • Set keyframes on any property (position, scale, rotation, opacity, color)
  • Use easing curves (ease-in, ease-out, spring, custom bezier)
  • Create multiple animation timelines (e.g., "idle", "hover", "pressed")
  • Blend animations together with mix values
3

Build a State Machine

This is what makes Rive special. Connect your animations with logic so they respond to user input without writing code.

  • Inputs: Trigger (fire-once), Boolean (on/off), Number (progress bars, sliders)
  • States: Link each state to an animation timeline
  • Transitions: Define conditions that switch between states
  • Listeners: Attach Pointer Enter, Pointer Exit, Click directly in the editor
4

Add Advanced Features Optional

Take it further with data binding, scripting, or dynamic assets depending on your use case.

  • Data Binding: Connect View Models to drive text, colors, visibility from data
  • Luau Scripting: Write code inside the editor for procedural logic
  • Components: Create reusable artboards that nest and compose
  • Dynamic Text: Change text content at runtime (names, scores, labels)
  • Asset Loading: Swap fonts, images, or audio dynamically
5

Export & Integrate

Export a .riv file and add it to your website with a canvas element and a few lines of JavaScript.

  • Export as .riv file (typically 10-50KB)
  • Choose asset strategy: Embedded (in file), Referenced (load separately), or Hosted (Rive CDN)
  • Add <canvas> element + Rive runtime script
  • Initialize with ~5 lines of JavaScript
6

Control from JavaScript

Optionally wire up runtime controls to respond to app logic, API data, or user actions beyond what the state machine handles.

  • Get state machine inputs: rive.stateMachineInputs('SM')
  • Fire triggers: trigger.fire()
  • Set booleans: input.value = true
  • Listen for events: rive.on(EventType.RiveEvent, callback)
  • Bind data with View Models for reactive updates

Complexity Guide

What you can build at each skill level.

Beginner

Animated icons, loading spinners, simple hover buttons, toggle switches.

  • 1-2 animation states
  • Basic shapes and colors
  • Simple triggers (click, hover)

Intermediate

Character animations, interactive forms, progress visualizations, multi-state buttons.

  • Multiple states + transitions
  • Bone rigging for characters
  • Number inputs for progress

Advanced

Data-bound dashboards, dynamic lists, runtime asset swapping, Luau scripted logic.

  • Data Binding + View Models
  • Components & nested artboards
  • Luau scripting for logic
